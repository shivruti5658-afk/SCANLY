# Scanly — Offline Document Scanner Web App

A mobile-first React/Vite document scanner. Uses the device camera, keeps images in browser memory, applies basic scan filters, and generates PDFs locally.

## Run
```bash
npm install
npm run dev
```
Then open the local URL on a phone/desktop browser. Camera access requires HTTPS in production (localhost is allowed for development).

## Build
```bash
npm run build
```
